\section*{Compiling and Running}

\subsection*{Prerequisites}
\begin{itemize}
	\item C++17 compiler (\texttt{clang++} or \texttt{g++})
	\item GNU Make
	\item Python 3 with packages: \texttt{numpy}, \texttt{pandas}, \texttt{matplotlib}
\end{itemize}

\subsection*{Compiling}
From the project root directory:
\begin{lstlisting}
mkdir out && make
\end{lstlisting}
This produces the executable \texttt{out/main}. To clean build artifacts:
\begin{lstlisting}
make clean
\end{lstlisting}

\subsection*{Running : Interactive Mode}
Run with no arguments to process a single matrix interactively:
\begin{lstlisting}
./out/main
\end{lstlisting}
You will be prompted to select a \texttt{.mtx} file from \texttt{data/}. The program runs the full optimization pipeline and prints the before/after metrics to the terminal.

\subsection*{Running : Benchmark Mode}
Run with the \texttt{--bench} flag to process all benchmark matrices with timing:
\begin{lstlisting}
./out/main --bench
\end{lstlisting}
This generates CSV results and permuted matrices under \texttt{out/}.

\subsection*{Generating Plots}
After running the benchmark, you can run the plotting scripts:
\begin{lstlisting}
python3 scripts/plot_benchmarks.py
python3 scripts/plot_optimization_metrics.py
python3 scripts/generate_report_tables.py
python3 scripts/plot_reordering.py
\end{lstlisting}
These read the CSV files from \texttt{out/} and produce figures and tables, also saved under \texttt{out/}.
